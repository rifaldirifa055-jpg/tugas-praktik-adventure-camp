## Deskripsi Program
Adventure Camp adalah program berbasis bahasa C untuk membantu penyewaan peralatan camping. Program dapat menampilkan daftar peralatan, menghitung biaya sewa dan diskon, menampilkan struk, serta menyimpan riwayat transaksi.

## Fitur Program
1. Melihat daftar peralatan dan harga.
2. Melakukan penyewaan peralatan.
3. Menghitung subtotal, diskon, dan total pembayaran.
4. Menampilkan struk penyewaan.
5. Melihat riwayat transaksi dan total pendapatan.
